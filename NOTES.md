# NOTES — things scaffolded but not verifiable on this machine

This project was scaffolded on a Linux VM with **no Xcode and no Apple SDK**,
so nothing here has been compiled. Everything below needs a first build on a
Mac to confirm.

## Not compiled

- All 19 Swift sources + 1 test file are written against SwiftUI / SwiftData
  (iOS 17) APIs from documentation and standard patterns, but **none have
  been type-checked**. Expect small fix-ups on the first Xcode build
  (most likely around `@Query` predicates, `FetchDescriptor` usage, and
  preview macros).
- The unit tests (`PerkPilotTests`) are written to be meaningful
  (recurrence boundaries, leap years, seed contract counts) but have never run.

## project.pbxproj

- Hand-generated by `tools/generate_project.py` (deterministic UUIDs).
  Structure was validated mechanically (all file references resolve, phases
  exist, braces balance), but it has never been opened in Xcode. If Xcode
  complains, regenerate with the script after fixing, or let Xcode repair it
  and check in the result.
- No `.xcworkspace`, no asset catalog, no entitlements file. An AppIcon set
  should be added in Xcode before any TestFlight/App Store submission.
- `DEVELOPMENT_TEAM` is empty and `CODE_SIGN_STYLE` is Automatic — Santosh
  must select his team in Xcode on first run.

## Behavior assumed, not tested

- SwiftData `@Attribute(.unique)` + cascade delete rules behave as documented.
- `SeedLoader` checksum: the manifest carries a `sha256:` checksum over the
  research payload (verified offline by `normalize_seed.py`), but the app
  does **not** re-verify it at import — it validates structure, counts,
  stable-ID uniqueness, cadence vocabulary, and the provenance rule instead.
- Idempotent re-import was reasoned through, not executed.
- `UNCalendarNotificationTrigger(dateMatching:day:28, repeats:true)` fires
  monthly — in February (28 days) it still fires on the 28th; behavior in
  shorter edge cases is Apple's documented behavior, untested here.
- CloudKit sync is **not** wired up (Phase 3 in the roadmap).

## Normalization decisions (automated, worth a human glance)

`tools/normalize_seed.py` folded tip-like research rows into parent benefits
and excluded non-benefits to reach the plan's 238 normalized benefits:

- Amex Platinum: 2 airline-fee tip rows → tips under "Airline incidental fee credit"
- Sapphire Reserve: "Double-Dip Hotel Credit Stack" → tip under "The Edit by Chase Travel Hotel Credit"
- Sapphire Preferred: excluded "No airport lounge access" and the discontinued
  10% anniversary bonus (non-benefits)
- Ink Business Preferred: excluded "Card identity note" (metadata)
- Delta Reserve: 5 strategy/quirks rows → tips under Sky Club access,
  companion certificate, MQD Boost, Delta Stays credit, Rideshare credit
- Robinhood Gold: 6 fee/program-rule rows → tips under "3% flat cash back";
  "No balance transfer fee" and "Late payment fee up to $40" kept as benefits
- Southwest: "DoorDash DashPass + quarterly grocery credit" split into annual
  DashPass membership + quarterly $10 credit (two records)

Counts verified programmatically: 12 cards / 238 benefits, matching the
architecture plan exactly.
